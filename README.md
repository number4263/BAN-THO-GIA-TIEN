# Bàn Thờ Gia Tiên & Thắp Nhang Ảo (Ancestral Altar & Virtual Incense)

Ứng dụng web tái hiện không gian thờ tự truyền thống Việt Nam, kết hợp công nghệ tương tác hiện đại và phong cách mỹ thuật thủy mặc tinh tế.

![Bàn Thờ Gia Tiên](public/favicon.ico)

---

## 🌟 Tính Năng Nổi Bật

1. **Nghi Lễ Thắp Nhang 10 Bước Tương Tác:**
   - Hướng dẫn tuần tự qua 10 bước trang nghiêm: Tĩnh tâm, chắp tay hai ngón cái, dâng hương, châm lửa tàn đỏ ngọn lửa li ti, lạy khấn và dâng nhang vào lư đồng.
   - Hiệu ứng âm thanh thiền định: Chuông gia trì, mõ tụng kinh, tiếng châm lửa, tiếng khánh thanh tịnh cùng phản hồi xúc giác (Haptic feedback).

2. **Chóp Tháp Gia Tiên Tam Cấp & Đơn Ảnh Thờ:**
   - Hỗ trợ xếp đặt ảnh thờ theo tôn ti trật tự:
     - **Tầng 1 (Đỉnh Tháp):** Cụ Thủy Tổ / Tiên Linh.
     - **Tầng 2 (Tầng Giữa):** Cụ Ông & Cụ Bà.
     - **Tầng 3 (Tầng Hạ):** Cha Mẹ & Thân Tộc.
   - Hiệu ứng chuyển di ảnh "fade-in" êm dịu, trang nghiêm kèm vầng hào quang linh thiêng.
   - Khung bài vị (Ihai) tối giản phong cách sơn mài Urushi và gỗ Hinoki.

3. **Mô Phỏng Vật Lý Khói Nhang Thủy Mặc:**
   - 3 làn khói nhang uốn lượn bay bổng mượt mà trên nền Canvas 60 FPS.
   - Biến thiên độ mờ đục (opacity) độc lập, tự nhiên theo từng nén nhang.
   - Bảng tùy biến thông số khói: Tốc độ bay, độ tản, độ dày và màu sắc khói.

4. **Cây Gia Phả & Phả Đồ Hệ Trực Hệ:**
   - Sơ đồ phả hệ trực quan qua nhiều thế hệ (từ Đời I đến Đời V).
   - Tra cứu tôn ti xưng hô, ngày giỗ âm lịch, nhánh chi họ và tiểu sử từng vị.
   - Quản lý sự kiện dòng họ, lễ giỗ kỵ định kỳ.

5. **Cá Nhân Hóa Không Gian Thờ:**
   - Bật/tắt gian thờ cổ truyền: Cột gỗ lim, hoành phi câu đối sơn son thếp vàng, đèn lồng cung đình.
   - Tải ảnh bàn thờ thật hoặc phòng thờ gia đình bạn để làm giao diện trực tiếp.
   - Cánh hoa sen và hoa mai rơi thanh thoát.

## 🛠️ Công Nghệ Sử Dụng

- **Frontend:** React 19, TypeScript, Vite
- **Styling & Layout:** Tailwind CSS v4, Motion (Framer Motion v12)
- **Icons & Graphics:** Lucide React, HTML5 Canvas 2D
- **Âm thanh:** Web Audio API & Synthesized sound engine (chuông khánh, tiếng mõ, lửa nhang)

---

## 🚀 Cài Đặt & Chạy Cục Bộ

```bash
# 1. Cài đặt các gói phụ thuộc
npm install

# 2. Khởi chạy môi trường phát triển (Port 3000)
npm run dev

# 3. Đóng gói cho production
npm run build
```
